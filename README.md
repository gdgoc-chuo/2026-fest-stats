# 2026-fest-stats

学園祭の受付で来場者が回答するキオスク型アンケートシステム。
カメラに手をかざす操作 (手の骨格認識)、マウス操作、または4キー (←・→・決定・戻る) のどれか1つだけで直感的に操作できる。

- 公開URL: https://gdgoc-chuo.github.io/2026-fest-stats/
- 動作確認用 (GAS と通信しないモック): https://gdgoc-chuo.github.io/2026-fest-stats/?mock

## 概要

- フロントエンド: GitHub Pages (`index.html` / `app.js` / `style.css` / `config.js`、ビルド不要)
- 保存先: GAS 経由の Google スプレッドシート (正) と、端末内の控え
    - 端末内の控えは、管理パネルで選んだフォルダの `responses.csv` に1件ずつ追記する (PC に残る控えはこれだけ)
    - ブラウザの localStorage (未送信キューなど) も使うが、Edge のキオスクモードは InPrivate で動くため、**Edge を閉じると消える**
- 認証: 端末に登録したトークンを GAS 側で照合。URL のみを知っている第三者による不正書き込みを防止

## 当日の操作

**管理パネルの起動方法**: 画面左下隅を2秒間長押しする (単発クリックでは反応しない。長押し中は画面最下部にプログレスバーが伸び、最大まで達すると表示される)。キーボード操作の場合は「戻る」を押しながら「決定」を2秒間長押し、または Ctrl+Shift+A (※環境により Edge のタブ検索ショートカットと競合する場合あり)。

### 事前セットアップしていない PC で始める

当日、別の PC を借りて使う場合などは、「開場前」の前にこの手順を行う。

#### 別PC - 必要なもの

1. Windows 10 / 11 と Microsoft Edge (どちらも標準で入っている)
2. カメラ (ノート PC の内蔵カメラでよい)。カメラ操作を使わないならマウスだけでよい
3. インターネット接続
4. トークン。開発チームから USB メモリなど、公開されない方法で受け取る (チャットや公開の場に貼らない)

#### 別PC - 方法 A: `kiosk.bat` を使う (おすすめ)

1. <https://github.com/gdgoc-chuo/2026-fest-stats> を開き、「Code」→「Download ZIP」でダウンロードして、デスクトップなどに展開する (フォルダ名は `2026-fest-stats-main` になる)。
2. 展開したフォルダ (`kiosk.bat` がある場所) に、トークンを1行だけ書いたファイル `gas_token` を置く (拡張子なし。メモ帳で保存するときは「ファイルの種類: すべてのファイル」にする)。
3. `kiosk.bat` をダブルクリックする。「発行元を確認できませんでした」「Windows によって PC が保護されました」と出たら、「実行」(または「詳細情報」→「実行」) を押す。
4. 以降は「開場前」の 3 から続ける。CSV の保存先には、展開したフォルダの中に自動でできた `data` を選ぶ。

#### 別PC - 方法 B: ファイルを置けない・`.bat` を実行できない PC

1. Edge で Ctrl+Shift+N を押して InPrivate ウィンドウを開く (閉じたときにトークン入りの URL が履歴に残らないようにするため)。
2. アドレスバーに `https://gdgoc-chuo.github.io/2026-fest-stats/#setup=<トークン>` と入力して開く。トークンは開いた直後に URL から自動で消える。
3. F11 で全画面にする。
4. 以降は「開場前」の 3 から続ける。CSV の保存先は、ドキュメントなどの中に新しく作ったフォルダを選ぶ (ダウンロードなどのシステムフォルダそのものは選べない)。
5. 方法 B はキオスクモードではないため、来場者がマウスで画面の上端に触れると全画面が解除されることがある。そのときは F11 で戻す。

#### 別PC - 借りた PC の片付け (終了時の手順のあと)

1. CSV の控え (`data/responses.csv` など) が必要なら USB メモリなどで回収する。スプレッドシートに全件そろっていれば必須ではない。
2. 展開したフォルダ (`gas_token` と `data` を含む) を削除する。
3. 方法 A を使った場合は、`%LOCALAPPDATA%\fest-kiosk` (エクスプローラーのアドレスバーに入力すると開ける) も削除する。

### 開場前

1. 受付カウンターに「1グループにつき1回、代表者の方がご回答ください」「カメラで手の動きを認識しています。映像は保存されません」の案内を掲示する。
2. `kiosk.bat` と同じ場所に `gas_token` があることを確認し、`kiosk.bat` を実行する。
3. カメラの使用許可を求められたら、マウスで「許可」を押す。
4. 管理パネルを開き、「CSV保存先を選ぶ」でフォルダ `data` を選ぶ。
5. 管理パネルの「状態」で次を確認する (緑の丸が付いていれば正常)。
    1. 「トークン」が「正常」
    2. 「CSV保存先」が `data/responses.csv`
    3. 「カメラ」が「動作中」 (カメラ操作を使う場合)
6. 「テストモード」のスイッチを ON にして、手・マウスで1〜2件答える。スプレッドシートの `responses` と `data/responses.csv` に行が増えることを確認する。
7. **「テストモード」のスイッチを OFF に戻す** (ON の間はスイッチが赤い。戻し忘れると本番の回答が集計から除外される)。
8. 「閉じる」で管理パネルを閉じ、画面左下に丸 (●) も四角 (□) も出ていないことを確認する。

### 開場中

1. 来場者には、まず親指と人差し指をつまんだまま1秒待って回答を始め、そのあと手を左右に動かして指をつまんで決定するよう案内する。操作に不慣れな来場者には、マウス操作を案内する。
    - 選び間違えた場合は、画面左上の「戻る」(キーボードでは「戻る」キー) で1つ前の設問へ戻れる。
2. 回答途中で20秒間無操作が続くと、10秒間のカウントダウン警告が表示される。そのまま操作がない場合は途中離脱 (`status=partial`) として自動保存され、初期画面へ復帰する (スタッフ側の操作は不要)。
3. 結果画面は8秒後に自動で初期画面へ遷移する。
4. 定期的に画面左下のインジケーターを確認する。ドットや四角が表示されていなければ正常稼働状態。

### 困ったとき

1. **左下に灰色のドット**: ネットワーク切断状態。回答はローカルに蓄積され、再接続時に自動送信される。即時反映したい場合は管理パネルから「今すぐ送信」を実行。
2. **左下に赤色のドット**: 認証トークンが未設定または不一致。Alt+F4 で一度ブラウザを閉じ、`gas_token` の内容を確認したうえで `kiosk.bat` を再起動する。
3. **左下に黄色の四角**: CSV 保存先フォルダが未選択、または書き込みエラー。管理パネルの「CSV保存先を選ぶ」から `data` フォルダを再指定する (同一ファイルを再選択しても二重記録はされない)。
4. **手の検出・決定感度が悪い**: 管理パネルの「決定の方法」で「手を止める」を選ぶ (同一選択肢上で1.5秒静止すると決定)。改善しない場合は「カメラ操作」のスイッチを OFF にし、マウス回答に移行する。
5. **来場者が手の動きを把握しづらそうにしている場合**: 管理パネルの「映像」で「鏡」を選び、薄い鏡像を画面全体に重ねる (来場者の顔が画面に映るため、必要な場合のみ使用)。
6. **管理パネルの「カメラ」が「エラー」表示**: 5秒ごとに自動再接続が行われる。復帰しない場合はカメラの物理的な接続状態を確認する。

### 終了時

1. 管理パネルを開き、「未送信」が 0 件であることを確認する (残件がある場合は「今すぐ送信」をクリック)。
2. 念のため「CSVを書き出す」をクリックし、全件バックアップをダウンロードフォルダへ書き出しておく (`synced` 列で送信完了状況の確認が可能)。
3. Alt+F4 で Edge を終了する (ブラウザ内キャッシュは破棄されるが、Google スプレッドシートおよび `data/responses.csv` に全データが保持される)。

### 1. スプレッドシートと GAS

1. Google ドライブでスプレッドシートを新規作成し、名前を `2026-fest-stats` に設定する (共有範囲は開発チーム限定)。
2. メニューの「拡張機能」→「Apps Script」を開き、画面左上のプロジェクト名を `2026-fest-stats-api` に変更する。
3. エディタ内の `Code.gs` の内容をすべて [gas/Code.gs](gas/Code.gs) のコードに置き換えて保存する。
4. 上部の関数選択ドロップダウンで `setup` を選択して実行する (初回実行時はアクセス権限の承認ダイアログが表示される)。
   - `responses` シートと `集計` シートが自動作成される
   - 認証トークンが発行され、実行ログに `TOKEN: ……` と出力される (値を手元に控えておく。リポジトリにはコミットしないこと)
5. 「デプロイ」→「新しいデプロイ」を開き、種類の選択で「ウェブアプリ」を選択。説明に `prod` と入力し、次のユーザーとして実行を「自分」、アクセスできるユーザーを「全員」に設定してデプロイを実行する。
6. 発行されたウェブアプリの URL (`https://script.google.com/macros/s/……/exec`) を [config.js](config.js) の `GAS_URL` に設定する。

`Code.gs` を更新した場合は、「デプロイ」→「デプロイを管理」から対象のデプロイ (`prod`) を編集し、バージョンで「新バージョン」を選択して再デプロイする (ウェブアプリの URL は維持される)。その際、説明欄を `prod v2` などのように更新する。

GitHub リポジトリの Settings → Pages → Deploy from a branch から `main` / `(root)` を選択して保存する。

### 3. キオスク端末のセットアップ

Edge のキオスクモードは InPrivate で動作するため、**Edge を終了するとトークンおよびブラウザ内キャッシュは破棄されます**。起動時は毎回以下の手順を実施してください。

1. `kiosk.bat` を実行する。認証トークンは `kiosk.bat` と同階層の `gas_token` ファイルから自動的に読み込まれる (本ファイルは Git 管理外のため、使用する PC へ手動で配置すること)。ファイルが存在しない場合は `kiosk.bat <TOKEN>` と引数に指定して実行する。トークンは URL ハッシュ経由で登録され、登録後は URL から即座に除去される。
2. 管理パネルを開き、「CSV保存先を選ぶ」から `data` フォルダを選択する。選択が完了するまでは画面左下に黄色のインジケーター (□) が表示され、選択完了とともに非表示となる。選択前に行われた回答は、選択完了時にまとめて一括出力される。
3. 端末名は初期状態で `reception-1` に設定されている (スプレッドシートの `device` 列に記録)。複数台で運用する場合は、管理パネル →「端末名を変える」から `reception-2` などに変更する。
4. 画面左下にステータスドットが表示されていなければ正常稼働状態 (灰色: 未確認・オフライン、赤色: トークン未設定または認証エラー)。
5. アプリケーションの終了は Alt+F4。終了前に必要に応じて管理パネルを開き、「未送信」が 0 件であることを確認する。

カスタムキーボードを使用する場合のキー割り当ては、[config.js](config.js) 内の `keys` に `KeyboardEvent.code` 形式で指定する。

### 4. カメラ操作 (手の骨格認識)

来場者はカメラに手をかざすことで非接触で回答できる。スタッフは従来どおりマウスやキーボードでの操作も可能。

- **回答開始の合図**: 通りがかりの人の手による誤反応を防ぐため、最初の設問では、親指と人差し指をつまんだまま1秒続けるまで手の操作を受け付けない (画面全体が白く覆われて中央に案内が出る。骨格よりも前に重なり、リングだけは覆いの上に出る。リングが大きくなり、つまんでいる間に扇形に塗られていく)。満ちると音が鳴って回答を始められる。回答を終えるか途中でリセットされると、再び合図待ちに戻る。マウス・キーボードは合図なしで操作できる。時間は `config.js` の `startHoldMs` で変えられ、0 にすると合図なしになる。
- **動作原理**: 手の水平位置に応じて選択中の項目が移動する (手の位置にポインタリングが表示される)。手の位置は、つまむ操作では親指と人差し指の先の中間 (つまむ点)、手を止める操作では手のひらの中心で測る。既定の決定操作は「親指と人差し指をつまむ (ピンチ)」。結果画面でピンチすると即座に初期画面へ戻る。2問目以降は、手を画面左上の「戻る」ボタンに合わせて決定すると1つ前の設問へ戻る。
- **プライバシー保護**: 映像解析はすべてブラウザ内 (MediaPipe Hand Landmarker) でローカル処理され、外部送信や保存は一切行われない。受付には「カメラで手の動きを認識しています。映像は保存されません」等の案内を掲示する。
- **カメラアクセス権限**: InPrivate ウィンドウの仕様上、起動ごとにカメラのアクセス許可ダイアログが表示されるため、スタッフがマウスで「許可」をクリックする。
- **外部リソース**: 初回起動時に MediaPipe (約 11MB) およびモデルデータ (約 8MB) を CDN から取得する。インターネット未接続環境ではカメラ操作は利用不可となる (マウス・キーボード操作は通常通り利用可能)。
- **稼働状態の確認**: 管理パネルの「カメラ」項目で稼働状態 (準備中 / 動作中 / エラー) を確認可能。映像が3秒以上更新されない場合や切断時は、5秒間隔で自動再接続が実行される。
- **運用中の設定変更**: 管理パネルの「設定」から切り替え可能。ブラウザ再起動時は [config.js](config.js) の `hand` 設定値に初期化される。

| 項目 | 選択肢 | 既定値 (`config.js` の `hand`) |
|---|---|---|
| カメラ操作 (スイッチ) | ON / OFF | `enabled: true` |
| 決定の方法 | つまむ (`pinch`) / 手を止める (`dwell`、同じ選択肢で1.5秒止めると決定。タイル下端にバーが伸びる) | `select: "pinch"` |
| 映像 (画面全体に重ねる) | 骨格 (`skeleton`、手の骨格を描く) / 鏡 (`mirror`、薄い映像の上に選択肢の輪郭を描く。来場者の顔が映る) / なし (`none`) | `preview: "skeleton"` |

反応が敏感すぎる・鈍すぎるときは、`config.js` の `pinchOn` / `pinchOff` (つまみの判定)、`xRange` (カメラ映像のどの範囲を画面の左右に対応させるか。縦は横と同じ縮尺になるよう自動で決まり、`yCenter` で上下の位置だけずらせる)、`dwellMs` を調整する。骨格・映像はリングと同じ対応で画面全体に描くので、指先とリングの位置がそろう。鏡の映像の濃さは `mirrorOpacity` で変えられる。

## データ仕様

`responses` シートの各行が1回分の回答データに対応する。

| 列名 | 内容 |
|---|---|
| received_at | GAS がリクエストを受信した時刻 (JST、ミリ秒精度) |
| id | 回答ごとの一意な UUID (重複排除キー) |
| seq | 端末内での連番 (通し番号) |
| status | 回答ステータス (`complete`: 完了 / `partial`: 途中離脱) |
| is_test | テストデータ識別フラグ (1: テストモード時の入力) |
| party_size | グループの人数 (1〜5、5 は「5人以上」を表す) |
| attribute | 来場者区分 (`student` / `applicant` / `alumni` / `other_univ` / `family_friend` / `general`) |
| with_kids | 小学生以下の子どもの同伴 (1: 同伴あり / 0: なし / 空文字: 単身来場のため未質問) |
| started_at / answered_at | 回答開始 (初回操作) / 回答確定の時刻 (端末基準、JST、ミリ秒精度) |
| duration_ms | 回答所要時間 (ミリ秒) |
| q_ms | 設問別の所要時間 (JSON 形式、ミリ秒) |
| input | 入力方式 (`hand`: カメラ / `key`: キーボード / `mouse`: マウス・タッチ / `mixed`: 併用) |
| device / app_version | 端末識別名 / アプリケーションのバージョン |

端末の `responses.csv` は、上の表から `received_at` を除いた列と同じ並びで、1行が1回答に対応する。

`集計` シートはスプレッドシートの数式によって自動集計され、来場者区分別・人数別・子ども同伴率・時間帯別の各集計結果がリアルタイムに反映される。
