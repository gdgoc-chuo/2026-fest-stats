# 2026-fest-stats

学園祭の受付で来場者が回答するキオスク型アンケートシステム。
マウス操作、または4キー (←・→・決定・戻る) だけで直感的に操作できる。

公開URL: https://gdgoc-chuo.github.io/2026-fest-stats/

## 概要

- フロントエンド: GitHub Pages (`index.html` / `app.js` / `style.css` / `config.js`、ビルド不要)
- 保存先: GAS 経由の Google スプレッドシート (正) と、端末内の控え
    - 端末内の控えは、管理パネルで選んだフォルダの `responses.csv` に1件ずつ追記する (PC に残る控えはこれだけ)
    - ブラウザの localStorage (未送信キューなど) も使うが、Edge のキオスクモードは InPrivate で動くため、**Edge を閉じると消える**
- 認証: 端末に登録したトークンを GAS 側で照合。URL のみを知っている第三者による不正書き込みを防止

## セットアップ

### 管理名称の一覧

| 対象 | 名称 | 備考 |
|---|---|---|
| スプレッドシート | `2026-fest-stats` | 共有範囲は開発チーム内に限定 |
| Apps Script プロジェクト | `2026-fest-stats-api` | スプレッドシートの拡張機能から作成 |
| Apps Script ファイル | `Code.gs` | 作成時の既定ファイルをそのまま使用 |
| 回答データシート | `responses` | `setup()` 実行時に自動生成 (シート名は変更不可) |
| 集計シート | `集計` | `setup()` 実行時に自動生成 (シート名は変更不可) |
| 既定の「シート1」 | 削除可 | 初期生成されるシート |
| スクリプトプロパティ | `TOKEN` | `setup()` 実行時に自動生成 |
| トークン控え (ローカル環境のみ) | `gas_token` | リポジトリ直下に配置 (`.gitignore` 対象)。確認用: `90***……***98` |
| ウェブアプリのデプロイ説明 | `prod` | 再デプロイ時は `prod v2`, `prod v3`, …… と版数を更新 |
| キオスク端末名 | `reception-1` | 既定値 (2台目以降は `reception-2`, …… を指定) |
| Edge キオスク用プロファイル | `%LOCALAPPDATA%\fest-kiosk` | `kiosk.bat` 実行時に自動作成 (既に開いている Edge に接続されないよう分けている。InPrivate のため中身は残らない) |
| CSV の保存先フォルダ | `data` | `kiosk.bat` と同じ場所に自動作成 (`.gitignore` 対象)。管理パネルで選ぶ。ダウンロードフォルダなどのシステムフォルダは選べない |

※ `responses` および `集計` のシート名、スクリプトプロパティの `TOKEN` はコード内で直接参照されているため、名前を変更すると正常に動作しなくなります。

### 1. スプレッドシートと GAS

1. Google ドライブでスプレッドシートを新規作成し、名前を `2026-fest-stats` に設定する (共有範囲は開発チーム限定)。
2. メニューの「拡張機能」→「Apps Script」を開き、画面左上のプロジェクト名を `2026-fest-stats-api` に変更する。
3. エディタ内の `Code.gs` の内容をすべて [gas/Code.gs](gas/Code.gs) のコードに置き換えて保存する。
4. 上部の関数選択ドロップダウンで `setup` を選択して実行する (初回実行時はアクセス権限の承認ダイアログが表示される)。
   - `responses` シートと `集計` シートが自動作成される
   - 認証トークンが発行され、実行ログに `TOKEN: ……` と出力される (値を手元に控えておく。リポジトリにはコミットしないこと)
5. 「デプロイ」→「新しいデプロイ」を開き、種類の選択で「ウェブアプリ」を選択。説明に `prod` と入力し、次のユーザーとして実行を「自分」、アクセスできるユーザーを「全員」に設定してデプロイを実行する。
6. 発行されたウェブアプリの URL (`https://script.google.com/macros/s/……/exec`) を [config.js](config.js) の `GAS_URL` に設定する。

`Code.gs` を更新した場合は、「デプロイ」→「デプロイを管理」から対象のデプロイ (`prod`) を編集し、バージョンで「新バージョン」を選択して再デプロイする (ウェブアプリの URL は維持される)。その際、説明欄を `prod v2` などのように更新する。

### 2. GitHub Pages

GitHub リポジトリの Settings → Pages → Deploy from a branch から `main` / `(root)` を選択して保存する。
公開 URL: `https://gdgoc-chuo.github.io/2026-fest-stats/`

### 3. キオスク端末のセットアップ

Edge のキオスクモードは InPrivate で動くため、**Edge を閉じるとトークンも端末内の控えも消える**。起動のたびに次の手順を行う。

1. `kiosk.bat` を実行する。トークンは `kiosk.bat` と同じ場所の `gas_token` ファイルから読まれる (このファイルは Git に入らないので、使うPCに手でコピーする)。ファイルが無いときは `kiosk.bat <TOKEN>` と引数で渡す。トークンは URL のハッシュで渡され、登録後すぐ URL から除去される。
2. 管理パネルを開き、「CSV保存先を選ぶ」でフォルダ `data` を選ぶ。選ぶまでは画面左下に朱色の四角 (□) が出ており、選ぶと消える。選ぶ前に答えた回答は、選んだ時点でまとめて書き出される。
3. 端末名は初期状態で `reception-1` に設定されている (スプレッドシートの `device` 列に記録)。複数台で運用する場合は、管理パネル →「端末名」から `reception-2` などに変更する。
4. 画面左下の丸い点が表示されていなければ正常稼働状態 (灰色: 未確認・オフライン、朱色: トークン未設定または認証エラー)。
5. アプリケーションの終了は Alt+F4。終了前に、必要なら管理パネルで未送信が 0 件であることを確認する。

カスタムキーボードを使用する場合のキー割り当ては、[config.js](config.js) 内の `keys` に `KeyboardEvent.code` 形式で指定する。

## 当日の操作

| 目的 | 操作方法 |
|---|---|
| 管理パネルを開く | 「戻る」を押しながら「決定」を3秒長押し / 画面左下隅を3秒長押し / Ctrl+Shift+A |
| 未送信データを送信する | 管理パネル →「今すぐ再送」をクリック (通常時は自動送信) |
| テストデータを投入する | 管理パネル →「テストモード: ON」に切り替え (`is_test=1` が付与され、集計対象から除外される)。※本番開始前に必ず OFF に戻す |
| 回答を PC のフォルダに保存し続ける | 管理パネル →「CSV保存先を選ぶ」でフォルダ `data` を選ぶ (起動のたびに必要)。以降の回答が `responses.csv` に追記される。同じファイルを選び直しても重複しない |
| その時点の控えを書き出す | 管理パネル →「CSV」または「JSON」をクリック (ブラウザのダウンロードフォルダに保存。`synced` 列で GAS への送信済みかも分かる) |

- 回答途中で20秒間無操作が続くと、10秒間のカウントダウン警告が表示される。そのまま操作がない場合は `status=partial` (途中離脱) として保存され、初期画面に戻る。
- 結果画面は8秒後に自動で初期画面へ戻る (キリ番演出発生時は14秒後)。

## データ仕様

`responses` シートの各行が1回分の回答データに対応する。

| 列名 | 内容 |
|---|---|
| received_at | GAS がリクエストを受信した時刻 (JST、ミリ秒精度) |
| id | 回答ごとの一意な UUID (重複排除キー) |
| seq | 端末内での連番 (通し番号) |
| status | 回答ステータス (`complete`: 完了 / `partial`: 途中離脱) |
| is_test | テストデータ識別フラグ (1: テストモード時の入力) |
| party_size | グループの人数 (1〜5、5 は「5人以上」を表す) |
| attribute | 来場者区分 (`student` / `applicant` / `alumni` / `other_univ` / `family_friend` / `general`) |
| with_kids | 小学生以下の子どもの同伴 (1: 同伴あり / 0: なし / 空文字: 単身来場のため未質問) |
| started_at / answered_at | 回答開始 (初回操作) / 回答確定の時刻 (端末基準、JST、ミリ秒精度) |
| duration_ms | 回答所要時間 (ミリ秒) |
| q_ms | 設問別の所要時間 (JSON 形式、ミリ秒) |
| input | 入力方式 (`key`: キーボード / `mouse`: マウス・タッチ / `mixed`: 併用) |
| device / app_version | 端末識別名 / アプリケーションのバージョン |

端末の `responses.csv` は、上の表から `received_at` を除いた列と同じ並びで、1行が1回答に対応する。

`集計` シートはスプレッドシートの数式によって自動集計され、来場者区分別・人数別・子ども同伴率・時間帯別の各集計結果がリアルタイムに反映される。
