# 2026-fest-stats

学園祭の受付で来場者が回答するキオスク型アンケートシステム。
カメラに手をかざす操作 (手の骨格認識)、マウス操作、または4キー (←・→・決定・戻る) のどれか1つだけで直感的に操作できる。

公開URL: https://gdgoc-chuo.github.io/2026-fest-stats/

## 概要

- フロントエンド: GitHub Pages (`index.html` / `app.js` / `style.css` / `config.js`、ビルド不要)
- 保存先: GAS 経由の Google スプレッドシート (正) と、端末内の控え
    - 端末内の控えは、管理パネルで選んだフォルダの `responses.csv` に1件ずつ追記する (PC に残る控えはこれだけ)
    - ブラウザの localStorage (未送信キューなど) も使うが、Edge のキオスクモードは InPrivate で動くため、**Edge を閉じると消える**
- 認証: 端末に登録したトークンを GAS 側で照合。URL のみを知っている第三者による不正書き込みを防止

## セットアップ

### 管理名称の一覧

| 対象 | 名称 | 備考 |
|---|---|---|
| スプレッドシート | `2026-fest-stats` | 共有範囲は開発チーム内に限定 |
| Apps Script プロジェクト | `2026-fest-stats-api` | スプレッドシートの拡張機能から作成 |
| Apps Script ファイル | `Code.gs` | 作成時の既定ファイルをそのまま使用 |
| 回答データシート | `responses` | `setup()` 実行時に自動生成 (シート名は変更不可) |
| 集計シート | `集計` | `setup()` 実行時に自動生成 (シート名は変更不可) |
| 既定の「シート1」 | 削除可 | 初期生成されるシート |
| スクリプトプロパティ | `TOKEN` | `setup()` 実行時に自動生成 |
| トークン控え (ローカル環境のみ) | `gas_token` | リポジトリ直下に配置 (`.gitignore` 対象)。確認用: `90***……***98` |
| ウェブアプリのデプロイ説明 | `prod` | 再デプロイ時は `prod v2`, `prod v3`, …… と版数を更新 |
| キオスク端末名 | `reception-1` | 既定値 (2台目以降は `reception-2`, …… を指定) |
| Edge キオスク用プロファイル | `%LOCALAPPDATA%\fest-kiosk` | `kiosk.bat` 実行時に自動作成 (既に開いている Edge に接続されないよう分けている。InPrivate のため中身は残らない) |
| CSV の保存先フォルダ | `data` | `kiosk.bat` と同じ場所に自動作成 (`.gitignore` 対象)。管理パネルで選ぶ。ダウンロードフォルダなどのシステムフォルダは選べない |

※ `responses` および `集計` のシート名、スクリプトプロパティの `TOKEN` はコード内で直接参照されているため、名前を変更すると正常に動作しなくなります。

### 1. スプレッドシートと GAS

1. Google ドライブでスプレッドシートを新規作成し、名前を `2026-fest-stats` に設定する (共有範囲は開発チーム限定)。
2. メニューの「拡張機能」→「Apps Script」を開き、画面左上のプロジェクト名を `2026-fest-stats-api` に変更する。
3. エディタ内の `Code.gs` の内容をすべて [gas/Code.gs](gas/Code.gs) のコードに置き換えて保存する。
4. 上部の関数選択ドロップダウンで `setup` を選択して実行する (初回実行時はアクセス権限の承認ダイアログが表示される)。
   - `responses` シートと `集計` シートが自動作成される
   - 認証トークンが発行され、実行ログに `TOKEN: ……` と出力される (値を手元に控えておく。リポジトリにはコミットしないこと)
5. 「デプロイ」→「新しいデプロイ」を開き、種類の選択で「ウェブアプリ」を選択。説明に `prod` と入力し、次のユーザーとして実行を「自分」、アクセスできるユーザーを「全員」に設定してデプロイを実行する。
6. 発行されたウェブアプリの URL (`https://script.google.com/macros/s/……/exec`) を [config.js](config.js) の `GAS_URL` に設定する。

`Code.gs` を更新した場合は、「デプロイ」→「デプロイを管理」から対象のデプロイ (`prod`) を編集し、バージョンで「新バージョン」を選択して再デプロイする (ウェブアプリの URL は維持される)。その際、説明欄を `prod v2` などのように更新する。

### 2. GitHub Pages

GitHub リポジトリの Settings → Pages → Deploy from a branch から `main` / `(root)` を選択して保存する。
公開 URL: `https://gdgoc-chuo.github.io/2026-fest-stats/`

### 3. キオスク端末のセットアップ

Edge のキオスクモードは InPrivate で動くため、**Edge を閉じるとトークンも端末内の控えも消える**。起動のたびに次の手順を行う。

1. `kiosk.bat` を実行する。トークンは `kiosk.bat` と同じ場所の `gas_token` ファイルから読まれる (このファイルは Git に入らないので、使うPCに手でコピーする)。ファイルが無いときは `kiosk.bat <TOKEN>` と引数で渡す。トークンは URL のハッシュで渡され、登録後すぐ URL から除去される。
2. 管理パネルを開き、「CSV保存先を選ぶ」でフォルダ `data` を選ぶ。選ぶまでは画面左下に朱色の四角 (□) が出ており、選ぶと消える。選ぶ前に答えた回答は、選んだ時点でまとめて書き出される。
3. 端末名は初期状態で `reception-1` に設定されている (スプレッドシートの `device` 列に記録)。複数台で運用する場合は、管理パネル →「端末名」から `reception-2` などに変更する。
4. 画面左下の丸い点が表示されていなければ正常稼働状態 (灰色: 未確認・オフライン、朱色: トークン未設定または認証エラー)。
5. アプリケーションの終了は Alt+F4。終了前に、必要なら管理パネルで未送信が 0 件であることを確認する。

カスタムキーボードを使用する場合のキー割り当ては、[config.js](config.js) 内の `keys` に `KeyboardEvent.code` 形式で指定する。

### 4. カメラ操作 (手の骨格認識)

来場者はカメラに手をかざして答える。スタッフはこれまでどおりマウスやキーボードも使える。

- **仕組み**: 手のひらの左右の位置で、指している選択肢が決まる (手の位置に朱色のリングが出る)。決定は既定で「親指と人差し指でつまむ」。結果画面でつまむと最初に戻る。
- **プライバシー**: 映像はブラウザ内 (MediaPipe Hand Landmarker) で処理し、送信も保存もしない。受付に「カメラで手の動きを読み取っています。映像は保存しません」などの掲示を出す。
- **カメラの許可**: InPrivate のため、起動のたびにカメラの使用許可を求められる。スタッフがマウスで「許可」を押す。
- **読み込み**: 起動時に MediaPipe (約 11MB) とモデル (約 8MB) を CDN から読み込む。ネットにつながっていないとカメラ操作は使えない (マウス・キーは使える)。
- **状態の確認**: 管理パネルの「カメラ」の行 (準備中 / 動作中 / エラー)。映像が3秒以上止まったり、カメラが使えなかったりしたときは、5秒ごとに自動でつなぎ直す。
- **当日の切り替え**: 管理パネルのボタンで切り替えられる。Edge を閉じると [config.js](config.js) の `hand` の値に戻る。

| 項目 | 選択肢 | 既定値 (`config.js` の `hand`) |
|---|---|---|
| カメラ | ON / OFF | `enabled: true` |
| 決定の操作 | つまむ (`pinch`) / 手を止める (`dwell`、同じ選択肢で1.5秒止めると決定。タイル下端にバーが伸びる) | `select: "pinch"` |
| 画面の表示 (左下の小窓) | 骨格だけ (`skeleton`) / 鏡のような映像 (`mirror`、来場者の顔が映る) / なし (`none`) | `preview: "skeleton"` |

反応が敏感すぎる・鈍すぎるときは、`config.js` の `pinchOn` / `pinchOff` (つまみの判定)、`xRange` (カメラ映像のどの範囲を画面の左右に対応させるか)、`dwellMs` を調整する。

## 当日の操作

**管理パネルの開き方**: 画面左下の隅を3秒長押しする (クリックでは開かない。押しているあいだ左下に朱色のバーが伸び、端まで伸びると開く)。キーボードなら「戻る」を押しながら「決定」を3秒長押しするか、Ctrl+Shift+A (Edge のタブ検索と重なるため効かないことがある)。

### 事前セットアップしていない PC で始める

当日、別の PC を借りて使う場合などは、「開場前」の前にこの手順を行う。

**必要なもの**

1. Windows 10 / 11 と Microsoft Edge (どちらも標準で入っている)
2. カメラ (ノート PC の内蔵カメラでよい)。カメラ操作を使わないならマウスだけでよい
3. インターネット接続
4. トークン。開発チームから USB メモリなど、公開されない方法で受け取る (チャットや公開の場に貼らない)

**方法 A: `kiosk.bat` を使う (おすすめ)**

1. https://github.com/gdgoc-chuo/2026-fest-stats を開き、「Code」→「Download ZIP」でダウンロードして、デスクトップなどに展開する (フォルダ名は `2026-fest-stats-main` になる)。
2. 展開したフォルダ (`kiosk.bat` がある場所) に、トークンを1行だけ書いたファイル `gas_token` を置く (拡張子なし。メモ帳で保存するときは「ファイルの種類: すべてのファイル」にする)。
3. `kiosk.bat` をダブルクリックする。「発行元を確認できませんでした」「Windows によって PC が保護されました」と出たら、「実行」(または「詳細情報」→「実行」) を押す。
4. 以降は「開場前」の 3 から続ける。CSV の保存先には、展開したフォルダの中に自動でできた `data` を選ぶ。

**方法 B: ファイルを置けない・`.bat` を実行できない PC**

1. Edge で Ctrl+Shift+N を押して InPrivate ウィンドウを開く (閉じたときにトークン入りの URL が履歴に残らないようにするため)。
2. アドレスバーに `https://gdgoc-chuo.github.io/2026-fest-stats/#setup=<トークン>` と入力して開く。トークンは開いた直後に URL から自動で消える。
3. F11 で全画面にする。
4. 以降は「開場前」の 3 から続ける。CSV の保存先は、ドキュメントなどの中に新しく作ったフォルダを選ぶ (ダウンロードなどのシステムフォルダそのものは選べない)。
5. 方法 B はキオスクモードではないため、来場者がマウスで画面の上端に触れると全画面が解除されることがある。そのときは F11 で戻す。

**借りた PC の片付け (終了時の手順のあと)**

1. CSV の控え (`data/responses.csv` など) が必要なら USB メモリなどで回収する。スプレッドシートに全件そろっていれば必須ではない。
2. 展開したフォルダ (`gas_token` と `data` を含む) を削除する。
3. 方法 A を使った場合は、`%LOCALAPPDATA%\fest-kiosk` (エクスプローラーのアドレスバーに入力すると開ける) も削除する。

### 開場前

1. 受付に「1グループにつき1回、代表者の方がご回答ください」と「カメラで手の動きを読み取っています。映像は保存しません」の掲示を出す。
2. `kiosk.bat` と同じ場所に `gas_token` があることを確認し、`kiosk.bat` を実行する。
3. カメラの使用許可を求められたら、マウスで「許可」を押す。
4. 管理パネルを開き、「CSV保存先を選ぶ」でフォルダ `data` を選ぶ。
5. 管理パネルの上部で次を確認する。
    1. 「トークン」が「正常」
    2. 「CSV保存先」が `data/responses.csv`
    3. 「カメラ」が「動作中」 (カメラ操作を使う場合)
6. 「テストモード: ON」にして、手・マウスで1〜2件答える。スプレッドシートの `responses` と `data/responses.csv` に行が増えることを確認する。
7. **「テストモード: OFF」に戻す** (戻し忘れると本番の回答が集計から除外される)。
8. 「閉じる」で管理パネルを閉じ、画面左下に丸 (●) も四角 (□) も出ていないことを確認する。

### 開場中

1. 来場者には、手をかざして左右に動かし、つまんで決定するよう案内する。うまくいかない来場者には、マウスで答えてもらう。
2. 回答途中で20秒操作がないと、10秒のカウントダウンが出る。そのまま放置されると途中までの回答が `status=partial` で保存され、最初の画面に戻る (スタッフの操作は不要)。
3. 結果画面は8秒で最初の画面に戻る (キリ番のときは14秒)。
4. キリ番 (50組ごと) の画面が出たら、来場者にお菓子を渡す。
5. ときどき画面左下を見る。丸も四角も出ていなければ正常。

### 困ったとき

1. **左下に灰色の丸**: ネットにつながっていない。回答は端末にたまり、つながれば自動で送られる。急ぐときは管理パネル →「今すぐ再送」。
2. **左下に朱色の丸**: トークンが未設定か間違っている。Alt+F4 で閉じ、`gas_token` を確認して `kiosk.bat` を実行し直す。
3. **左下に四角**: CSV の保存先が未選択か、書き込みに失敗した。管理パネル →「CSV保存先を選ぶ」で `data` を選び直す (同じファイルを選んでも重複しない)。
4. **手の反応が悪い**: 管理パネル →「決定: 手を止める」に切り替える (同じ選択肢で1.5秒止めると決定)。それでもだめなら「カメラ: OFF」にしてマウスで答えてもらう。
5. **来場者が手の動きを分かりにくそう**: 管理パネル →「映像: 鏡」に切り替える (来場者の顔が画面に映るので、必要なときだけ)。
6. **管理パネルの「カメラ」が「エラー」**: 5秒ごとに自動でつなぎ直す。直らなければカメラの接続を確認する。

### 終了時

1. 管理パネルを開き、「未送信キュー」が 0 件であることを確認する (0 でなければ「今すぐ再送」)。
2. 念のため「CSV」を押して、その時点の控えをダウンロードフォルダに書き出す (`synced` 列で送信済みかも分かる)。
3. Alt+F4 で Edge を閉じる (閉じるとブラウザ内のデータは消えるが、スプレッドシートと `data/responses.csv` には残る)。

## データ仕様

`responses` シートの各行が1回分の回答データに対応する。

| 列名 | 内容 |
|---|---|
| received_at | GAS がリクエストを受信した時刻 (JST、ミリ秒精度) |
| id | 回答ごとの一意な UUID (重複排除キー) |
| seq | 端末内での連番 (通し番号) |
| status | 回答ステータス (`complete`: 完了 / `partial`: 途中離脱) |
| is_test | テストデータ識別フラグ (1: テストモード時の入力) |
| party_size | グループの人数 (1〜5、5 は「5人以上」を表す) |
| attribute | 来場者区分 (`student` / `applicant` / `alumni` / `other_univ` / `family_friend` / `general`) |
| with_kids | 小学生以下の子どもの同伴 (1: 同伴あり / 0: なし / 空文字: 単身来場のため未質問) |
| started_at / answered_at | 回答開始 (初回操作) / 回答確定の時刻 (端末基準、JST、ミリ秒精度) |
| duration_ms | 回答所要時間 (ミリ秒) |
| q_ms | 設問別の所要時間 (JSON 形式、ミリ秒) |
| input | 入力方式 (`hand`: カメラ / `key`: キーボード / `mouse`: マウス・タッチ / `mixed`: 併用) |
| device / app_version | 端末識別名 / アプリケーションのバージョン |

端末の `responses.csv` は、上の表から `received_at` を除いた列と同じ並びで、1行が1回答に対応する。

`集計` シートはスプレッドシートの数式によって自動集計され、来場者区分別・人数別・子ども同伴率・時間帯別の各集計結果がリアルタイムに反映される。
